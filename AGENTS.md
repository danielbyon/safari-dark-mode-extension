## Agent skills

### Issue tracker

Issues and specs are tracked in this repo's GitHub Issues; use `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default labels for the five canonical triage roles. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout: root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Repository contribution policy

This repository is public for GitHub Actions compute benefits, not community development. Do not solicit or accept external contributions or merge outside contribution patches. Evaluated third-party dependencies may be used under commercially compatible terms. See `docs/adr/0001-proprietary-application-source.md`.
