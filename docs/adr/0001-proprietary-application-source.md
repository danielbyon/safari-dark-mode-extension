# Public application source with noncommercial reuse

The owner selected PolyForm Noncommercial 1.0.0 for new original project material while retaining commercial distribution of the App Store product. The repository remains public solely to retain the public-repository GitHub Actions compute benefit, not to solicit community development. Noncommercial use and experimentation are intentional permissions; this selection is not a promise to prohibit every competing noncommercial derivative.

This supersedes the earlier all-rights-reserved-only direction. The root LICENSE contains the unmodified official PolyForm text. NOTICE identifies the owner, the scope of the change, and the earlier MIT baseline.

## Consequences

1. Public visibility is intentional. Standard public GitHub-hosted runners, including standard macOS runners, provide free compute independent of the private-repository allowance; larger runners remain metered and normal service limits apply.
2. Earlier MIT grants remain intact. The baseline is commit abb389a93a2b73f76030072328f448a7cd7d5065. The exact earlier notice remains in docs/legal/legacy-mit-notice.txt; prospective restrictions do not remove permissions already granted for MIT-licensed material.
3. Third-party code remains under its own license. Commercial usability and required notices must be checked for the actual components selected.
4. The owner's commercial distribution rights, the public source license, incoming contribution permissions, and the App Store customer contract are distinct. Commercial rights to another contributor's new code must not be assumed from a noncommercial outbound license alone. The owner does not accept external contributions to this project. Do not solicit or merge outside code or other contribution patches. No contributor agreement or community contribution workflow is needed. This does not prohibit selecting independently licensed third-party dependencies under Q6, nor explicitly submitted product support reports.
5. The selected text expressly permits listed personal and organizational uses. Do not summarize it as prohibiting all organizational use, or add an unselected anti-competition restriction.
6. PolyForm Noncommercial's distribution grant does not repeat the permitted-purpose wording used by its use and modification grants. Upstream issue 87 raises the consequence for resale of unchanged copies without a definitive maintainer resolution. Do not promise a blanket prohibition on every resale scenario.
7. A license restricting commercial fields of use is source-available rather than open source under the OSI definition. This terminology does not change GitHub's public-repository billing criterion.

## Alternatives considered

| Alternative | Difference from the selected policy |
| --- | --- |
| All rights reserved | Would withhold the noncommercial permissions the owner selected. |
| PolyForm Strict 1.0.0 | Omits modification and distribution grants, reducing permitted experimentation. |
| Prosperity 3.0.0 | Adds a limited commercial evaluation period that was not selected. |
| PolyForm Shield 1.0.0 | Permits noncompeting commercial use and restricts competing products, including free competitors; it pursues a different goal from noncommercial reuse. |
| Creative Commons noncommercial licenses | Creative Commons recommends software-specific licenses for code because of source-distribution and patent considerations. |
