# Rendering candidate audit

Dark Reader 4.9.135 is a credible candidate for a Safari rendering probe. Its published API reaches a dynamic renderer that watches styles and has an explicit teardown path. Three requirements carry enough risk to change that assessment: preserving a site's own dark appearance during and after transformation, preserving content images while offering independent dimming, and reading styles under Safari's permission and execution-world rules. **Safari execution, visual comparisons, restoration, accessibility outcomes and resource measurements are all `NOT_RUN`.** The decision here is whether there is enough evidence to test the candidate. Engine selection belongs after those tests. [Comparison protocol](rendering-comparison-protocol.md)

## 2. What could be reused

1. **Public library.** `enable` accepts a partial theme and optional fixes for the current document. `disable` tears down the dynamic theme, `isEnabled` reads a library flag, `auto` follows system color preference, `setFetchMethod` supplies a resource loader, and `exportGeneratedCSS` collects generated styles. The API rejects alternative rendering engines. It accepts one resolved fix object. The host would own activation, entitlement, scope resolution, frame grants and preview lifetime. [Public declarations][types] · [API implementation][api]
2. **Internal renderer.** The entry point calls `createOrUpdateDynamicThemeInternal`. It creates overrides, manages stylesheets, watches changes, tracks inline declarations and CSS variables, treats shadow roots separately and removes managed state on disable. The extension has another entry point which selects relevant fixes. Extracting the renderer would also bring its watchers, caches, proxy, cleanup and browser-specific assumptions under local maintenance. [Dynamic engine][engine] · [Stylesheet management][sheets] · [Variable handling][vars]
3. **Extension infrastructure.** The extension's content script starts its detector from background messages. The detector checks metadata and site hints, can temporarily disable recognized generated sheets, and samples computed colors. Its ordinary ready-page check returns after evaluation. A sustained transition observer with reliable self-exclusion is still an open requirement. The full extension also owns tab messaging, configuration loading and fix matching. None of these is a public library operation. [Content script][inject] · [Detector][detector] · [Configuration loader][loader]
4. **Site data.** The upstream parser understands CSS, inversion selectors and exclusions for inline styles, image analysis and stylesheet URLs. An adopter could supply a reviewed local subset through the fixes argument. Some host-specific behavior also lives in renderer code, including style placement on selected hosts. Each update must therefore review code and data together. Bundled fixes consume the product's eligibility decision and carry a diagnosable version. The upstream remote loader and PDF-specific treatment fall outside the accepted website scope. [Fix parser][parser] · [Style placement][placement] · [ADR 0009](../adr/0009-bundled-compatibility-configuration.md)
5. **Fork risk.** Passing effective values or a bounded fix through a documented argument can be tested as a small adapter. Maintaining a copy of the detector, patching color-role transformation, or changing image analysis couples the product to internals. On each proposed upstream update, compare the pinned revisions, public declarations, generated files, dependencies, licenses and selected fixes. Replay the affected fixtures. Estimate recurring patches from the observed failures before committing to that work. [Technical feasibility plan](technical-feasibility.md)

## 3. Commercial use, notices and dependencies

The distributed library includes the MIT license with the 2026 Dark Reader Ltd. copyright notice. It expressly permits commercial distribution with the required notice. On this evidence the public library has a viable commercial route. If selected, retain the complete license and notice with copies or substantial portions, including the distributed application and any redistributed source. The owner's original work falls under PolyForm Noncommercial 1.0.0. Earlier MIT grants remain in force, and third-party material keeps its own terms. These conclusions concern the specified files. The commercial application's assets and implementation have no established reuse grant here. ## 4. Product capability matrix

**Evidence labels.** *Documented* means a published interface or platform statement. *Source* means a code path inspected at the recorded revision. The right column gives the inference, limitation and the observation needed to resolve it. Every empirical question below is `NOT_RUN`. The accepted [glossary](../../CONTEXT.md), [preference semantics](../adr/0002-scoped-preference-inheritance.md), [website scope](../adr/0006-website-rendering-scope.md) and [appearance controls](../adr/0007-first-release-appearance-controls.md) define success.

| Requirement | Documented or source evidence | Gap and required observation |
|---|---|---|
| Activation and restoration | Documented enable/disable. Teardown removes managed sheets. For website theme-color metadata, it writes back the first nonempty value it retained, which can overwrite a later site update. [Metadata restoration][meta] [API][api] · [Cleanup][engine] | Cycle with pending work. Compare against the current site-authored state, including a changed theme-color on an SPA route, input and focus. Check disable, preview discard and permission loss. |
| Dynamic styles | Source watches style nodes, inline attributes, variables, shadow roots and adopted sheets. SVG fill/stroke have specialized paths. [Engine][engine] · [Inline styles][inline] · [Variables][vars] | Mutate each independently after first paint. Test CSSOM updates, accessible shadow roots and SVG semantic distinctions. Report inaccessible roots separately. |
| Cross-origin stylesheets | Source first tries CSSOM. For unreadable links/imports it may load CSS text, resolve nested imports and construct a sheet. Before the public fetch hook runs, a guard can reject a resource by scheme, host, port or host count. The default hook also rejects. [Dispatch][dispatch] · [Origin checks][guard] [Sheet loader][sheets] · [Fetch hook][fetch] · [API messaging shim][shim] | Record whether the hook was reached. A candidate rejection and a Safari denial have different remedies. Vary CORS and resource grants independently. A failed load can leave an empty copy or missing overrides while the original sheet still styles the page. Check denial, redirect, revocation and partial rendering. |
| Native dark mode | Documented `auto` follows system appearance. Website detection and hints are internal. The detector excludes recognized sheets during sampling. On WP Dark Mode pages the renderer removes site-owned active markers and creates an observer to repeat that removal. Its teardown has no reference to disconnect this observer. [Conflict handler][conflict] [API][api] · [Detector][detector] | Test repeated checks on extension-darkened light content with default and custom colors, then independent site transitions. Also reactivate the site theme after disable in the same document. Persistent suppression would require an engine change or another method if a public integration cannot prevent it. Count false positives, negatives and oscillations. |
| Adaptive appearance | Source transforms background, foreground and border roles using input colors and theme poles. [Color transforms][colors] | Compare brand hues, legibility and state distinctions against extension-off references. |
| Palette colors | Documented background/text poles. Link color lacks an independent declared field. [Declarations][types] | Test custom background, text and links including visited/focused links. A bounded link override is plausible only if it preserves state distinctions throughout eligible content. |
| Brightness, contrast, saturation, warmth | Documented brightness, contrast, grayscale and sepia. Source composes color matrices. [Declarations][types] · [Matrix][matrix] | Measure each independently. Grayscale and sepia do not establish the required saturation range or warmth behavior. Check palette and media interactions. |
| Independent appearance overrides | Source merges supplied fields into defaults. [API][api] | Resolve theme then each inherited field outside the engine. Verify reapplication, override removal and narrower-scope precedence without modifying a reusable theme. |
| Independent image dimming, default off | Source analyzes background pixels for size, brightness and transparency. It can hide large light images. Fixes can exclude selected images from analysis. [Image analysis][images] · [Background decisions][bg] | No documented classified-content dimmer. Compare identical artwork as an image and CSS background, plus icons and video, with dimming off and on. Determine whether preservation needs an engine change. |
| Media fidelity | Source uses different paths for image URLs, SVG attributes and CSS colors. [Background decisions][bg] · [Inline styles][inline] | Compare photographs, screenshots, illustrations, video frames, chart series and semantic colors. Record when the renderer alters meaning or removes content. |
| Frames | Source detects whether the current document is framed. The library lacks the product's permission and top-level preference resolver. [API][api] · [Apple permissions][permissions] | Vary top-level eligibility, frame grant and frame-native appearance independently, including nested frames and cross-origin navigation. |
| Bounded fixes | Documented fix object and source CSS substitutions. The extension has separate data and matching logic. [Declarations][types] · [Fix parser][parser] | Record fix version and affected element. Apply required fix to eligible preview on a saved-Off or native-dark page. Denied, inactive-access and paused previews must remain untouched. Preserve deliberate choices. |
| Accessibility | Source transforms colors. The upstream interface makes no product-wide contrast guarantee. [Color transforms][colors] · [WCAG 2.2][wcag] | Measure product-controlled code, every unmodified built-in theme and adaptive output. Attribute pre-existing site defects and deliberate low contrast separately. Test warning and accessible, guided recovery plus unrelated regressions while customized. |
| Safari and OS | Source targets ES2020 for the API. On import it wraps an existing chrome.runtime.sendMessage and discards the native return value. A same-world caller expecting a promise can lose its reply. It also inserts a stylesheet proxy via a script element and uses constructible sheets for CSS copies. WebKit added constructible and adoptable sheets in Safari 16.4. [Target][target] · [Shim][shim] · [Engine][engine] · [WebKit 16.4][webkit] | Check an ordinary host request/reply before import, after import and after disable. Screen script worlds, CSP, injection timing and degraded paths on iPhone, iPad and Mac. Safari 16.4 is a boundary for this sheet operation. T2 screens capabilities per platform, T7 sets deployment floors. [ADR 0004](../adr/0004-capability-based-os-support.md) |
| Performance | Source observes mutations, caches transformed colors and analyzes image pixels. [Engine][engine] · [Images][images] | Measure first paint, interaction latency, peak/settled memory, CPU during mutations and after idle/disable. Cost and comparative ranking remain open. |

## 5. Decision after the audit

Test the published boundary first. A permission-aware loader and mapping resolved values to public arguments are plausible adapters. Whether Safari can safely support them belongs to the [capability investigation](https://github.com/danielbyon/safari-dark-mode-extension/issues/3). The [rendering comparison](https://github.com/danielbyon/safari-dark-mode-extension/issues/4) must show whether the detector, color controls and media classification need internal changes. Compare a static or filter method only against a reproducible unresolved failure. A substantial permanent fork, unclear asset rights or an unmet mandatory requirement needs an owner decision. The [qualification investigation](https://github.com/danielbyon/safari-dark-mode-extension/issues/8) owns final release gates.
